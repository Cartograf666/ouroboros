# Subagent Delegation Architecture in Ouroboros

## 1. Core Components
- **Scheduler** (schedule_subagent): Initiates child tasks with specific roles
- **Task Monitor** (wait_task, peek_task): Tracks execution state
- **Result Manager** (get_task_result, integrate_subagent_patch): Handles completions
- **Durable Records**: task_results/* JSON files with status and outputs

## 2. Delegation Flow
1. **Initiation**: schedule_subagent() with subagent_id and objective
2. **Execution**: Child runs in isolated workspace with:
   - `task_drive/` for input/output
   - `runtime_data/` for temporary state
3. **Monitoring**:
   - `peek_task(task_id)` for status checks
   - `wait_task()` for blocking completion
4. **Result Handling**:
   - `get_task_result(task_id)` for output
   - `integrate_subagent_patch()` for code integration

## 3. Durable State Persistence
- Task state saved in: `task_results/<task_id>.json`
- Output artifacts stored in: `artifact_store/` (files, screenshots, logs)
- Error states include: `blocked`, `failed`, `cancelled`

## 4. Key Parameters
```python
{
  'subagent_id': 'required',
  'objective': 'string',
  'expected_output': 'description',
  'memory_mode': 'empty|forked',
  'write_surface': 'read_only|self_worktree'
}
```

## 5. Error & Recovery
- Use `cancel_task()` for aborts
- `peek_task()` shows: 
  - `live_child_status` (running/terminal)
  - `child_beacons` (questions/blockers)
- `discard_child_result()` for cleanup

## 6. Artifact Lifecycle
1. Generated by subagent execution
2. Stored in `artifact_store/`
3. Accessible via: 
   - `get_task_result()`
   - `view_image()` for media
   - `send_file()` for delivery
